# 🌍 Explore Mundo - Países Turísticos

Projeto desenvolvido com o objetivo de apresentar destinos turísticos ao redor do mundo de forma interativa, destacando a cultura, história e principais atrações de cada país.

---

## 📖 Sobre o Projeto

O **Explore Mundo** é um site que reúne informações sobre diferentes países turísticos em uma interface moderna e responsiva. Cada país possui sua própria página contendo uma breve apresentação, curiosidades, história e pontos turísticos.

O projeto foi desenvolvido utilizando apenas tecnologias Front-End.

---
